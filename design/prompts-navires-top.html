Vues de dessus — les trois navires gratuits

Le pion du navire sur la carte doit montrer le navire actuel du joueur vu de dessus. Les sept navires achetés ont leur vue (ship-skin-*-top) ; il manque celles de la ligne gratuite : le Rafiot, le brigantin et le galion. Le code est déjà branché : dès qu’un fichier est posé, il sert ; sinon la vue générique reste en secours.

Réglages
  • Joindre pour CHAQUE prompt : la vue de profil du navire concerné (assets/ship-player-1.webp, -2 ou -3) et une vue de dessus existante pour l’angle et l’échelle (assets/ship-skin-royal-top.webp).
  • Fond transparent, même cadrage et même taille apparente que la vue de dessus de référence (le pion doit garder la même emprise sur la carte).
  • Conversion : cwebp -q 82 entree.png -o assets/ship-player-<n>-top.webp (1 = Rafiot, 2 = brigantin, 3 = galion).
